TTL-LAMa installation files
============================

Generated by scripts/install/configure.py. Review the generated Podman commands before running them.

Directory layout:
- etc/ttl-lama/ contains application, VPN backend, SSH configuration, and ssh_known_hosts.
- run/secrets/ contains the private SSH key and Flask secret key. Keep this directory private and do not publish it.
- opt/ttl-lama-vpn/ contains the VPN host setup script and its supporting files.
- .env.example lists environment variables that must be configured in .env.

Before startup:
1. Copy .env.example to .env and complete the required values.
2. Add the verified VPN host key to etc/ttl-lama/ssh_known_hosts. Obtain it from a trusted source and verify its fingerprint independently. Strict host key checking remains enabled.
3. Review the generated Podman commands and run them manually.

Application data is stored in a Podman named volume mounted at /data. The initial administrator password is in etc/ttl-lama/config.yml for bootstrap; remove it after the first persisted initialization.

If OpenVPN was selected, its generated files are documentation only and do not provide a runnable backend.
