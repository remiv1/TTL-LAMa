TTL-LAMa installation files
============================

Generated by scripts/install/configure.py. Review the generated Podman commands before running them.

Directory layout:
- etc/ttl-lama/ contains application, VPN backend, SSH configuration, ssh_known_hosts, and optional panic configuration files.
- run/secrets/ contains the private SSH key, Flask secret key, and optional SMTP password. Keep this directory private and do not publish it.
- opt/ttl-lama-vpn/ contains the VPN host setup script and its supporting files.
- .env.example lists environment variables that must be configured in .env.

If configured, an executable panic-script placeholder is created under etc/ttl-lama at the relative path you selected for the container. Paste your script into that file before starting the container; it is mounted read-only. SMTP settings are stored in panic_mail_config.yml; an SMTP password is stored separately under run/secrets.

Before startup:
1. Copy .env.example to .env and complete the required values.
2. Add the verified VPN host key to etc/ttl-lama/ssh_known_hosts. Obtain it from a trusted source and verify its fingerprint independently. Strict host key checking remains enabled.
3. Review the generated Podman commands and run them manually.

Application data is stored in a Podman named volume mounted at /data. Podman adjusts the volume ownership for the container user on startup. The initial administrator password is in etc/ttl-lama/config.yml for bootstrap; remove it after the first persisted initialization.

If OpenVPN was selected, its generated files are documentation only and do not provide a runnable backend.
