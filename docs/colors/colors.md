# Direction de l'identité visuelle

Cela suggère une identité visuelle qui mélange confiance + temporalité + sobriété technique, avec une petite dose de personnalité apportée par le lama.

Ma recommandation : « Sage + Amber »

| Rôle | Couleur | Hex | Ce qu’elle raconte |
| --- | --- | --- | --- |
| Primaire | Vert sauge sombre | #3F5D50 | confiance, contrôle, infrastructure |
| Secondaire | Sauge moyen | #708F7D | accès accordé, état sain |
| Accent | Ambre | #E6A23C | temps limité, échéance, bail |
| Accent clair | Sable | #F2D49B | côté chaleureux, lama, humanisation |
| Fond clair | Ivoire froid | #F5F7F4 | sobriété, lisibilité |
| Fond sombre | Anthracite vert | #18231E | console / infrastructure sans tomber dans le noir pur |
| Texte | Presque noir | #17201C | lisibilité |

## Pourquoi cette direction est particulièrement adaptée

🟢 Le vert n'évoque pas seulement « succès ».
 Le sauge sombre donne une impression de système stable et maîtrisé. Cela correspond bien au positionnement de TTL-LAMa : l'administrateur définit les profils et les politiques restent sous le contrôle de l'opérateur.

🟠 L'ambre devient la couleur du temps.
 C'est probablement le choix le plus important. L'accès n'est pas simplement on/off : il expire. Le README insiste justement sur les accès limités dans le temps, la date d'expiration et la révocation automatique.
 Je réserverais donc l'ambre aux éléments comme :

durée du bail ;
compte à rebours ;
« expire dans 18 min » ;
renouvellement ;
jauges temporelles ;
pictogramme ⏱️.

## Langage visuel très identifiable

Et pour les états fonctionnels

Je ne confondrais pas la palette de marque avec les couleurs d'état :

Vert #2E8B57 → bail actif
Ambre #D99027 → expiration proche
Rouge #C94C4C → révoqué / erreur
Gris #758078 → expiré / inactif

C'est intéressant conceptuellement : un bail expiré n'est pas une erreur. C'est le fonctionnement normal du système, puisque l'accès est précisément conçu pour disparaître à l'expiration.

Donc je privilégierais gris pour “expiré” et rouge uniquement pour quelque chose qui mérite réellement l'attention.

## Ce qui doit être évité

Le bleu cybersécurité omniprésent.
 Bleu électrique + noir + cadenas donnerait immédiatement une esthétique « VPN / Zero Trust / cybersecurity SaaS ». Or TTL-LAMa précise justement qu'il n'est ni une interface générale d'administration réseau, ni un remplacement de WireGuard, ni un fournisseur d'identité généraliste.

Le vert fluo façon terminal.
 Trop « hacker » pour un projet dont la proposition me semble davantage être la maîtrise du cycle de vie des accès.

Une surabondance de rouge.
 Une expiration attendue n'est pas une alerte de sécurité.

Le petit détail qui ferait l'identité

Je verrais très bien le logo TTL-LAMa 🦙⏱️ en vert sauge, avec le symbole lié au temps en ambre.

Par exemple :

TTL-LAMa #3F5D50 + ⏱ #E6A23C

On obtient immédiatement les deux idées :

🦙 identité sympathique + ⏱ accès éphémère

sans transformer le projet en produit fantaisiste.

## En résumé

Si je devais arrêter une direction maintenant, je choisirais :

Sauge foncé #3F5D50 comme couleur de marque + Ambre #E6A23C comme couleur du TTL.

Le sauge dit« accès maîtrisé » ; l'ambre dit« cet accès a une durée ». Et le sable apporte juste assez de chaleur pour que le lama puisse devenir un élément mémorable de l'identité.

C'est, à mon avis, beaucoup plus distinctif qu'un énième projet réseau bleu/noir.
